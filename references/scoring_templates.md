# 猎聘招聘自动化 - 评分权重模板库

## 使用方法
在搜索候选人时，引用对应岗位的评分模板，或根据模板自定义权重。

---

## 1. CFO / 财务高管（v2.0 更新）

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 上市公司财务总监经验 | **25** | 有A/H/美股上市公司财务总监/CFO经验得满分；拟上市公司财务负责人扣10分；无则0分 |
| 融资成功经历 | **20** | 主导完成股权融资≥3轮且累计金额≥3亿人民币得满分；2轮或金额1-3亿扣5-10分；无融资经验0分 |
| 投资/银行从业经验 | **20** | PE/VC/投行/商业银行从业≥10年得满分；5-10年扣5-10分；无相关经验0分 |
| 上市公司财务规范 | **15** | 熟悉A股/H股/美股披露规则、内控规范、审计对接得满分；仅了解扣5-8分 |
| 注册会计师(CPA) | **10** | 有CPA/ACCA得满分；中级会计职称扣5分 |
| 四大/顶级事务所 | **5** | 德勤/普华永道/毕马威/安永背景得满分 |
| MBA/EMBA | **5** | 中欧/长江等Top MBA满分；普通MBA扣2分 |
| 资深加分 | +2~+5 | 15年+加2分，20年+加5分 |

**面试挖掘问题（融资/投资经验未在简历中体现时）：**
1. "请列举您主导完成的所有股权融资项目，每轮的领投方、融资金额、估值是多少？"
2. "您在投资机构/银行的工作年限？参与过哪些重大项目的尽职调查或投后管理？"
3. "作为CFO，您如何搭建与资本市场（投行/分析师/投资人）的沟通机制？"
4. "请描述一次您主导的财务规范整改经历（如审计调整、内控缺陷修复）。"

**适用场景：** 上市公司 / 拟上市公司 CFO、集团财务总监

## 2. CTO / 技术高管

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 大厂技术管理经验 | **25** | BAT/字节/TMD等技术VP/总监以上 |
| 技术栈匹配 | **20** | 与目标技术栈一致 |
| 团队管理规模 | **15** | 管理50人+团队满分；20-50人扣5分 |
| 开源影响力 | **10** | GitHub高星项目/KVM/docker等知名开源贡献 |
| 名校背景 | **10** | CS名校/PhD优先 |
| 创业/IPO经历 | **10** | 有创业公司CTO或上市技术负责人经验 |
| 架构能力 | **10** | 有大规模系统架构设计经验 |

**适用场景：** 公司CTO、技术VP、研发总监、平台架构师

## 5. 投融资总监 / VP

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| IPO/上市经验 | **30** | 有完整IPO操盘经验（A股/H股/美股） |
| 融资资源/渠道 | **20** | 有VC/PE/FA机构人脉或成功融资案例 |
| 尽职调查/合规 | **15** | 有DD/合规内控/财务审计经验 |
| 行业认知 | **15** | 对目标行业有深度理解（按岗位设定） |
| 资本市场资质 | **10** | 保代资格/CFA/CPA等 |
| 沟通谈判力 | **10** | 有投资人对接/路演/融资谈判经验 |

**适用场景：** 投融资总监、IR总监、董秘、资本运作VP

## 7. 通用快速评分模板（轻量版）

当用户未指定详细评分标准时，使用此默认模板：

| 维度 | 默认权重 | 说明 |
|------|----------|------|
| 岗位核心技能 | **40** | 与JD最相关的核心能力 |
| 经验匹配度 | **25** | 工作年限+行业经验 |
| 教育背景 | **15** | 学历+学校+专业相关性 |
| 综合素质 | **10** | 稳定性+软实力+成长性 |
| 地区/薪资匹配 | **10** | 期望城市和薪资是否合理 |
